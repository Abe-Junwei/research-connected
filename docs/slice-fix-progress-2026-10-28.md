## 本轮可运行验证

执行 Node 命令时使用 `OPENSSL_CONF=/dev/null`。无新增依赖。

- TypeScript：`node node_modules/typescript/bin/tsc --noEmit --skipLibCheck`
- ESLint：`node node_modules/eslint/bin/eslint.js src preview --max-warnings 0`
- 架构、UI 合同、反馈链接：`node scripts/verify-architecture.mjs`、`node scripts/verify-ui-contract.mjs`、`node scripts/verify-feedback.mjs`。
- 离线组合：`node esbuild.config.mjs verify`，然后 `node scripts/verify.cjs --offline`；包括新增组合规则测试。
- 插件迁移与真实临时文件恢复：`node scripts/verify-plugin-state.mjs`。
- 共享阅读/笔记外改与有限重试：`node scripts/verify-reading-workflow.mjs`。
- 浏览器：`node esbuild.config.mjs review-browser` 后加载生成检查页，完整回归通过。使用实际动画帧，不伪造可见性。覆盖既有 UI、双 mount、换项目、并发重载、嵌入及实际 Crossref 适配器的固定网络样本任务链。
- 生产构建：`node esbuild.config.mjs production`，退出码 0。
- 编辑器自带 TypeScript 6 对旧 `moduleResolution: node` 有弃用提示；仓库 TypeScript CLI 检查通过，本轮未为消除编辑器提示迁移模块解析策略。

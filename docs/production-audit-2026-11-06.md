## 问题与修复方向

### P1：Semantic Scholar 在反代层断路，且服务端版本落后

证据：真实 POST /api/semantic-scholar 返回 404；浏览器显示 Semantic Scholar: Not found，S2 匹配 0/98。Caddy 的 /api/* 全部转给 9186，后者不实现该路径。9185 虽 active，线上 s2_proxy.py 仍是旧版，只接受旧 preview API 路径且未允许 graph Origin；本地新版已增加这两项。因此仅修改 Caddy 还不够。

处理：同步新版 S2 服务文件，增加专用 /api/semantic-scholar→9185 路由，保留现有请求体限制、队列、缓存和私密头剥离。验证新域名 Origin、单篇 GET 包装和 batch POST 包装确实到达上游。匿名上游仍可能 429，不能把解除 404 等同于稳定增强。

### P1：浏览器身份与标签页会话混用

web/session-auth.ts 将 token 放 localStorage、nonce 放 sessionStorage。新标签页没有 nonce，会新建会话并覆盖共享 token；旧页随后发送新 token+旧 nonce，服务端拒绝。额度按 token 计量，新标签页还会得到新的个人次数。

本地使用真实 QuotaStore、临时文件复现：A 完成一次后剩余9；新建 B 剩余10；B token+A nonce 返回 session_invalid。未在生产伪造成功操作。

处理：稳定匿名浏览器身份独立于短期标签页会话；新标签页及会话续期必须保留浏览器计次归属，不覆盖其他标签页凭证。补双标签页、关闭重开、12小时过期及任务确认回归。

### P1：OpenAlex 代理未执行会话和独立查询限速校验

证据：带合法 Origin 但不带 token/nonce 的 POST /api/openalex，线上仍返回200。handler 在读取 session_creds 前直接处理此路径。队列限制并发，但没有对这类单篇补查做每浏览器/IP的持续请求限速；建图启动限速不覆盖此接口。

处理：代理入口校验会话，并为所有外部查询补独立速率/总量控制，覆盖不扣操作次数的单篇查询。Origin 校验不能代替这些限制；CLI 可自行设置 Origin。

### P2：本地预算是固定估算，不能当作数据源真实余额

线上 OPENALEX_REQUEST_COST_USD=0.0001，成功响应固定结算，HTTP错误及超时退款；代码不读取上游实际用量。当前展示的预算余额来自本地账本，未独立核对 OpenAlex 账户。尤其超时并不能证明上游未消费。

处理：核对上游账户实际限额/用量及计费规则，按可验证口径计量；不确定结果保守占用预算。页面区分本地估算与上游剩余额度，验证不会启用付费充值。本次不声称已验证真实 $1 硬上限。

### P2：发布版本协调未实现

静态 web.js/styles.css 固定文件名，缓存1小时；未找到前后端版本协商及新版提示机制。后续发布可能混用新 HTML 与旧 JS，长期打开的旧页也无法按规格暂停不兼容操作。

处理：构建资源内容哈希或明确版本化，增加接口兼容版本校验；保留本地查看/复制，按已确认规格提示用户更新，不强刷任务。

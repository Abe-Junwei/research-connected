# Research Connected 独立网页版实施规格

日期：2026-11-06，北京时间。状态：**需求经用户两轮确认；本文记录实施目标，不代表已经实现或验收。**

中文产品名于 2026-11-07 确定为 **文现**，英文名保留 **Research Connected**。网页页签、载入页、工作台品牌与站点说明采用该命名。技术标识及本地存储键保持不变。

## 1. 产品目标与交付边界

研究人员带着 DOI 查询现有相似性图谱，筛选并复制所需文献信息。保留现有图谱语义、核心算法和既有文献组织能力；不改成另一种图谱。

- 面向外部用户免登录试运营，不要求访客填写数据源 Key。
- 文献导出保持 BibTeX、YAML、Markdown 文本复制；不新增文献文件下载或 PDF 下载。
- 支持部分增强缺失：图谱仍可用时允许完成，但必须说明来源失败、采样不足、摘要或向量缺失；不能把缺失信号描述成已验证结果。
- 不增加账号项目同步或后台任务恢复。

### 代码边界

同一仓库，明确分开正式 Web、Obsidian 插件和服务端入口；复用图谱核心，各自独立构建和发布。

本规格中的额度、网页路由、移动端交互、存储处理和更新策略**只用于正式网页版**。插件保持现有功能、交互和存储行为。优先通过 Web 入口和适配层实现；确需修改共享代码时，必须验证插件行为不变。不能把浏览器预览构建或静态部署等同于完成正式 Web 产品。

## 2. 正式入口与切换

- 正式入口：`https://graph.jieyu.ai`。
- 不迁移旧预览项目；用户已确认旧页无人使用。
- 正式版上线时撤下旧预览应用，旧地址直接返回 404，不做重定向。
- 只调整研究产品入口，status 仪表盘保留原有登录保护。
- 2026-11-06核查时，公开 DNS 对 `graph.jieyu.ai` 返回 NXDOMAIN；专用部署配置未发现系统 OpenAlex Key。这两项为上线前置条件，不是已完成配置。

## 3. 访问、用量与计次

### 三层限制

| 限制 | 已确认规则 |
|---|---|
| 浏览器操作额度 | 每浏览器每天最多10次成功操作；接受清除浏览器数据可绕过个人次数限制 |
| 全站操作额度 | 每天最多500次成功操作；不能承诺每天一定完成500次 |
| OpenAlex 用量 | 系统提供 Key，仅用每天$1免费额度，不启用付费充值；实际剩余额度可能先于500次耗尽 |
| 浏览器并发 | 同一浏览器同时最多1个建图、重建或深挖任务，跨标签页也适用 |
| IP启动速率 | 同一公网IP每分钟最多启动10次任务，失败尝试也受限制；超出提示稍后重试 |

浏览器与全站每日额度统一在北京时间08:00重置。页面显示浏览器剩余次数、全站可用名额、重置时间及当前限制原因；运行中的临时占用不得被当作永久扣次。

### 什么扣次数

| 动作与结果 | 计次 |
|---|---|
| 新建图，至少取得种子和1篇邻居，完整保存成功 | 扣1次 |
| 重建有效图并完整保存，即使文献集合完全相同 | 扣1次；启动前明确提示会使用次数 |
| 深挖，成功新增文献并完整保存 | 扣1次 |
| 深挖没有新增文献 | 不扣次数，仍受请求速率及数据源用量限制 |
| 只有种子、没有邻居 | 展示单篇详情并说明未取得邻居，不扣次数 |
| DOI无法解析、网络失败、取消、任务超时、保存失败 | 不扣次数 |
| 增强部分缺失，但满足可用图谱与保存条件 | 正常计次 |
| 查看本地项目、复制导出、布局和筛选 | 不扣次数 |
| 单篇元数据、摘要、引用证据补查 | 不扣操作次数，受接口速率及数据源总用量限制 |

浏览器或全站操作额度耗尽时暂停新建、重建、深挖；已有项目仍可查看、复制和补查单篇信息。数据源额度**分别处理**：OpenAlex用完则暂停其请求，其他来源仍可在自身限制内补查。界面必须区分操作次数耗尽、数据源用量耗尽、短时限流和网络失败。

## 4. 名额与任务生命周期

1. 服务端检查浏览器并发、IP速率、浏览器日额度和全站名额。
2. 允许启动时临时占用1个名额，预留有效期最多5分钟；拒绝启动不能产生部分新任务。
3. 请求完成且结果满足成功条件后，先完整保存到浏览器，再向服务端确认正式扣除浏览器与全站次数。
4. 失败、取消或到期停止接收结果，释放临时名额；重复确认、取消或释放不能重复扣次或返还。
5. 保存成功但确认时断网：保留成果，在原5分钟有效期内自动重试。到期仍未确认则释放名额、不追扣；用户已接受这类异常少计次数。

临时占用及确认归属于启动时的额度周期；跨08:00确认不能把上一周期操作再扣到新周期。过期任务不能在恢复网络后重新落入已过期的操作。

服务端的匿名浏览器额度、全站成功次数、有效临时名额必须跨进程重启保留到对应周期或有效期结束，随后清理。服务器不能独立验证浏览器存储已成功；以受约束操作的确认协议记账，不能宣称可绝对防止匿名客户端绕过计次。数据源总用量约束仍须独立生效。

### 页面中断与取消

- 不提供后台任务恢复。刷新、关闭或手机切后台后再次打开，若已有完整结果则读取，否则重新操作；中断任务占用到期释放。
- 用户切项目时，先提示当前任务将取消；确认后使旧任务结果失效并释放名额，再打开目标项目。
- 取消不能保证收回已发送到上游的数据请求，也不能退回已消耗的上游额度；只停止后续请求和过时结果的应用。

## 5. 项目存储、更新与多标签页

### 日常保存

项目仅保存在当前浏览器。空间不足时保留已有完整项目，明确显示本次保存失败，提供清理旧项目后重试的操作；不自动删除旧项目，不自动缩减快照，本次不扣次数。

重建期间旧图保持可查看、切详情和复制；新图完整保存成功才替换旧图。任务进行时暂停收藏、排除、阅读状态等项目修改，结束后恢复。失败保留旧图。

来源失败导致新图比旧图明显缩水时，保留旧图，提示数据不完整，由用户明确选择是否采用；只有采用且完整保存后计次。实现时应将失败来源和新旧文献数量作为可复查证据，不能用不透明分数自动替换。单纯缺少向量不能被当作新图文献缩水。

### 多标签页

- 同一项目同时只允许一个标签页编辑；其他标签页可查看和复制。
- 编辑页关闭后可接管；另提供明确的“接管编辑”操作，处理后台或崩溃页面占用。
- 接管使原编辑者及其运行中任务失效，释放相关临时名额；新编辑者从最近完整保存项目开始。
- 旧标签页恢复后转为只读，重新读取最新项目后才能再次争取编辑权；不得用迟到任务覆盖新编辑者保存的数据。
- 不同项目的编辑权可独立，但浏览器全局仍只能有一个建图、重建或深挖任务。

## 6. 手机、平板、浏览器与详情路由

正式验收范围：电脑 Chrome、Edge、Safari；iPhone/iPad Safari；Android Chrome。电脑、平板、手机均完整支持建图、深挖和复制。其他浏览器尽力兼容，不增加微信内置浏览器或Firefox的正式承诺。

触控规则：单指拖空白平移、双指缩放、点击节点查看详情。深挖通过详情中的明确按钮操作，不依赖鼠标右键、悬停或长按。

手机端论文详情为独立页面。浏览器返回恢复原图缩放、位置及选中节点。详情链接携带 DOI 或作品 ID；跨设备或他人打开时仅查询并展示该文献，不自动新建原图，不携带原浏览器的收藏、阅读状态或排除记录。优先读取本地已有文献信息，缺失才查询，单篇请求不扣操作次数。

剪贴板拒绝写入时，展示可选中的完整导出文本供手动复制，格式不变，不自动改为下载文件。键盘、触屏及屏幕阅读器均能操作主要控件，加载、保存失败及额度变化有可理解提示。

## 7. 数据告知与服务端留存

开始页清楚说明：项目只保存在当前浏览器，清除站点数据可能丢失；查询会发送给文献数据源。查询按钮附近保留简短提示，另有完整数据与存储说明；不新增确认弹窗。

服务端只持久保留必要的匿名浏览器标识、操作计数和临时名额。IP仅用于短时限流。公开文献数据允许限时共享缓存；不持久记录个人DOI查询历史，不引入7天或30天查询追踪。日志、错误收集、反向代理日志也须满足该留存边界，不能只检查业务数据库。缓存失效不代表用户项目被删除。

## 8. 构建、发布、页面更新和回滚

- 验证通过后直接更新 `graph.jieyu.ai`，保留上一部署版本以便回滚；不另设测试站。
- Web发布不能触发插件发版或替换用户安装的插件。
- 不强制刷新正在使用的页面。提示新版，由用户完成或取消任务并保存后更新。
- 小版本保持服务端接口兼容；不兼容更新时，旧页面保留已有数据的本地查看和复制，暂停新建、重建、深挖并提示更新。
- 服务版本回滚与浏览器项目数据的恢复是两件事，不能把“保留上一版部署”描述成保留项目备份。

### 用户明确接受的存储格式升级例外

仅网页版允许原地转换项目格式，不要求迁移备份。用户明确接受转换失败可能丢失项目、收藏、排除、阅读状态及手工扩展，页面须说明失败并提示重新建图。网站回滚后，允许清空旧版无法识别的数据并提示重新建图。

此例外只适用于格式升级失败或旧版无法识别新格式；**不适用于日常保存失败**，不能借此清理空间不足时的旧项目，也不得影响插件数据。相关失败须可识别，不能在普通临时网络错误时清空项目。

## 9. 实施顺序与验收

以下顺序组织工作，不改变已确认范围：

1. 分离正式Web入口、浏览器适配层、服务端入口及发布命令；保留插件回归基线。
2. 接入系统OpenAlex额度、持久计次、5分钟占用、IP速率和数据源独立用量限制。
3. 完成保存失败保护、重建替换、多标签页接管和过时结果隔离。
4. 完成独立详情路由、触控、剪贴板回退和使用告知。
5. 验证兼容更新及明确接受的格式失败行为；配置正式域名，发布并撤下旧入口。

必须提供可复跑证据：

| 验收组 | 最低覆盖 |
|---|---|
| 插件隔离 | Web独立构建；共享代码改动后插件功能、存储和宿主网络适配回归通过 |
| 成功条件 | 种子+1邻居计次；只有种子不计；重建集合不变计次；深挖无新增不计 |
| 额度 | 浏览器第11次拒绝；全站并发不超500；08:00切周期；重启不重置；IP第11次启动受限 |
| 记账 | 保存失败、取消、5分钟到期释放；重复确认幂等；确认断网保留成果；过期结果不得晚写 |
| 预算 | 只用OpenAlex免费用量；用尽与速率429、网络错误区分；其他来源可独立继续 |
| 数据保护 | 配额不足不破坏旧图；存储满不删旧快照；部分失败重建缩水需确认 |
| 多标签页 | 单编辑者、主动接管、原任务失效、恢复只读、全浏览器任务并发限制 |
| 移动与路由 | 所有承诺浏览器实测触控、详情返回位置、直接详情链接、复制拒绝回退；静态截图不能代替交互验证 |
| 发布 | 老页面继续本地使用、不兼容请求受控、部署回滚；格式升级失败与不识别格式的提示和已接受清理行为 |
| 隐私与入口 | 无持久个人DOI日志；匿名计次数据按期清理；正式域名可访问、旧预览404、status仍需登录 |

测试结果须注明真实设备、模拟环境和未验证项。现有浏览器预览回归通过不能替代整套正式版验收。

## 10. 已有实现与上线缺口

[S2网页部署记录](s2-web-deployment-2026-11-06.md)记录了已部署的预览通道：同域S2代理、匿名访问、GET/POST共享队列和缓存，及一例真实查询摘要补全。没有获批的专用S2 Key，匿名429仍会发生，没有验证可用向量。

该记录中的内存6500次尝试上限**不是本规格的持久500次成功操作系统**。当前OpenAlex直连也不是系统Key代理。正式域名、独立Web入口、额度与生命周期、移动详情路由、格式升级策略均需实现及验收后才能标为完成。

### 后续发现的数据质量问题（2026-11-06）

用户截图中的`Regularity in semantic change`对应OpenAlex `W1973826788`：摘要字段实际为目录，作者为Traugott/Dasher，但DOI `10.1075/clscc.15.c10`指向2024年另一部书的章节。首次排查发现共享摘要解析器只去前导标签，网页也信任非空摘要。后续已在Web适配层补充目录、导航、纯链接筛查及异常记录的基础身份核对，未启用到插件，也未硬合并或改写原始文献身份。

第二例`W564766481`当前API已返回规范记录`W4213325732`和正常摘要，截图旧目录还涉及旧快照与源记录变化。[系统排查报告](research/openalex-quality-audit-2026-11-06.md)区分已实现的内容筛查与尚待完成的规范ID迁移、缓存重验证、旧图分数重算和全链路可信度。目录过滤不能被当作全库身份纠错已完成。


## 后续范围变更：插件来源质量处理

2026-11-06 用户明确要求“插件的也改掉”“更新插件”：摘要内容筛查、元数据复核、可靠规范 ID 迁移、旧分数/关系失效处理、质量提示与导出警示现在也适用于插件。复用共享纯逻辑，但插件继续通过 Obsidian requestUrl 和插件数据 API 读写，保留个人密钥、文献笔记写入与原有交互；不接入 Web 的 S2 系统代理、浏览器存储或未来访客额度。手机交互、Web 路由和公开服务限制等其他条款仍仅适用于独立网页版。

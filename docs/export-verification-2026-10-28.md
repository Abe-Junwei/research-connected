# 导出功能验证（2026-10-28）

范围：主面板与笔记嵌入的 BibTeX、YAML、Markdown 表格、文献笔记，以及收藏清单复用的格式化函数。本文记录本轮实际检查；浏览器使用离线图谱、可控剪贴板与笔记写入适配器，不代表真实 Obsidian 文件系统验收。

结果：完整离线测试、生产构建、预览构建和完整浏览器回归均通过。最终浏览器回归包含中英文导出矩阵与收藏清单操作，页面 `body.dataset.result` 为 `passed`。

## 已复现并修复

1. **BibTeX 改写原文且未转义 TeX 字符**：原先直接删除 `{`、`}`、反斜杠，百分号、下划线等直接进入字段。现在保留字面字符并转义 TeX 特殊字符；新增先失败后通过的回归。
2. **BibTeX 丢失已知题录**：已有期刊/书名、卷、期、页码未输出。现在按文献类型输出 `journal` 或 `booktitle`，并保留已有卷期页码，不补造来源没有的值。真实 BibTeX `plain` 处理和 LaTeX 编译通过。
3. **空 YAML 导出为 null**：`papers:` 被 YAML 解析为 null。现在输出 `papers: []`，保持集合类型；实际 YAML 解析器验证通过。
4. **Markdown 表格保留回车**：原先仅移除换行，独立 CR 或 CRLF 中的 CR 仍进入单元格。现在统一归一化 CR/LF，题名中的管道符继续转义。
5. **嵌入绕过阅读冲突保护**：主面板阻止未确认进度创建笔记，嵌入却仍复制/写入带默认进度的笔记。浏览器回归先在嵌入失败；现与主面板一致，要求先确认进度。

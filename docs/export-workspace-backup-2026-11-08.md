# 文献导出及工作区备份：实施与验证

用户经 grilling 确认范围并授权实施。初次发布 Web build：`a6852e7f0d8135e0`，bundle：`web-L3Q2OI6Q.js`。

## 已实现

- Web 与 Obsidian 插件主面板、笔记嵌入图共享“导出文献”菜单：默认当前筛选，可选完整图谱；排除已排除的版本，不把候选目录误作图谱成员；取消起点例外。每项一个展示版本/全部符合条件版本可选，显示实际条目数。
- BibTeX、YAML、CSV 和单篇 Markdown 支持下载及复制；表格复制内容为 Markdown，按钮按后续确认统一显示“复制”。CSV 使用 UTF-8 BOM、引号/换行转义并防止公式执行；完整作者与编者分别保留。
- Markdown 始终生成当前选中文献的笔记骨架，未选中时用种子；插件沿用现有模板。插件“写入笔记”独立保留原有去重和关联行为，下载/复制不会写入库或导出现有笔记全文。
- 窄屏菜单按视口定位，避免左侧越界；窗口变化时重新定位。插件继续仅支持桌面，未更改 manifest 的平台声明。
- 仅 Web 增加“工作区”菜单：备份、恢复、清空。备份包含最新图谱及当前未保存视角/筛选、收藏、排除、深挖、全部跨图阅读和版本记录；不包含偏好、密钥、浏览器身份、额度、锁或任务。
- JSON 格式独立版本，20 MB 上限；支持只有文献记录而没有图谱。严格检查结构、视角、状态、图谱数据、数组上限及危险对象键，拒绝未知备份版本。
- 恢复预览显示日期、种子、节点/关系、收藏/排除/深挖和阅读/版本记录数量，确认后完整替换，不合并。写入使用同一浏览器锁及预览修订检查；失败保持当前数据。
- 恢复要求空闲且有编辑权，先使旧异步任务失效，保存成功后重新加载页面，确保同种子也还原保存视角。来源查询关闭标志持久化，不做自动补查/重采样，不使用额度；成功主动建图后再启用来源补查。
- 恢复与清空确认均提供可选“下载当前备份”；下载不会执行替换或清空。下载提示仅声称已发起，提醒检查文件保存，并不假称自动保存故障已修复。
- 恢复保留布局、筛选、缩放、中心、选中状态及侧栏；逐个节点坐标按已确认范围不备份，重新计算排布。

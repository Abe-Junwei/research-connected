# Research Connected 星空主题调研

调研日期：2026-10-27。范围：公开官方页面、官方帮助与演示图，以及本仓库当前截图和渲染实现。以下“星空感”是视觉分析，不代表厂商自称天文主题。未登录付费产品、未做用户测试，未修改产品代码。

## 结论

建议采用“文献星图”：保留现有紧凑研究工作台，把论文节点、关系连线和社区组织成可读的星座。优先参考 Obsidian 的克制与 Cosmograph 的空间层次，适量借鉴 InfraNodus 的彩色主题网络。首版提供可选的星图外观；外观独立于平面／时间线／径向布局，不新增布局或更换渲染引擎。

我们通常呈现几十篇论文，适合稀疏星座。Cosmograph 大规模点云的银河观感依赖大量真实数据点，不能靠添加假论文或随机亮点复制。

## 现有设计的基础

- `docs/images/graph-pane.png`：当前是暖白、石墨文字、赭金操作色的工作台，中央图谱与右侧证据区分工清楚。
- `.superdesign/design-system.md`：既有方向是安静的编辑式工具，并明确限制装饰、渐变和额外颜色。星图是建议新增的外观变体，不能把本报告当作已经修改设计规范。
- `src/map-canvas.ts`：共享 Canvas 负责背景渐变、节点、聚焦关系、标签与经典论文光晕；背景已有 CSS 变量入口。
- `src/visual.ts`：节点半径基于年均被引指标的图内缩放，种子有最低尺寸；已有按节点错相的呼吸函数。
- `src/community-regions.ts`：已有社区区域几何和主题标签工具，但当前 `draw()` 未绘制这些区域；有工具不代表星云背景已经存在。
- `src/graph-surface.ts`：主图与笔记内嵌共用画布外壳。后续实现应覆盖两处，避免两套主题。

## 推荐视觉规则

以下是待验证的设计参数，不是已完成的界面或经过对比度验证的配色。

| 元素 | 建议 | 保留的数据含义 |
| --- | --- | --- |
| 背景 | 近黑海军蓝，例如 `#101722`；面板用稍亮的 `#18212D`。先用静态底色。 | 背景没有数据含义，不放可被误认为论文的亮点。 |
| 论文 | 保留实心色核，辅以很薄的柔光。节点大小继续使用现有指标。 | 面积不改成“论文质量”；光晕不扩大点击区域。 |
| 种子 | 复用赭金身份，给稳定细环，明确标为种子。 | 作为当前探索起点，不强制移到中心或改写布局。 |
| 社区 | 同一社区共享克制色系，形成不同星群。 | 年份／主题／宿主配色模式继续由原图例解释，不能全部覆盖为社区色。 |
| 关系 | 全局为低强度细线，聚焦时提高连接亮度并保留关系类型色。 | 线宽沿用相关度，引用方向箭头保留；不添加装饰性连接。 |
| 选中 | 清楚的描边和标签，邻域亮起，其余适度变暗。 | 状态优先于装饰，不能仅靠颜色区分。 |
| 标签 | 概览只保留必要标签，悬停／选中时清楚显示作者与年份。 | 灰化不能使当前选中论文不可读。 |
| 详情区 | 保持普通研究面板、分隔线、清晰正文；跟随宿主明暗。 | 摘要、证据与导出操作仍使用直白名称。 |

视觉重心：中央像星图，边上仍是易读的研究工具。浅色模式维持纸面星图；深色模式呈现夜空，不强制整个 Obsidian 变暗。具体新色值需在设计稿阶段统一纳入外观 token。

## 最小实施顺序

1. 使用同一份约 50 篇论文的固定预览数据，对比当前外观与星图外观。保持坐标、筛选和选中论文一致，让对比只反映视觉变化。
2. 首版只调整画布底色、节点色核／柔光、种子环与线／标签的对比度。复用现有 Canvas 与主题入口，主题切换不请求网络、不重新计算布局。
3. 联动检查主图与内嵌。当前边线、种子环、阴影有写死的灰色／深色值，单改 CSS 背景会造成深色下看不见；应在共享画布的主题颜色读取处统一处理。
4. 有真实阅读反馈后，再考虑低透明社区雾区；它只能表达当前样本的聚类，不能宣传为学科边界。首版不添加星云纹理。

## 验收与限制

- 同一数据在两种外观下：节点数、边数、位置、尺寸指标、筛选结果与论文动作一致。
- 深浅主题、主图／内嵌都可读；选中描边、聚焦边线、箭头和标签分别检查。小字对比度以 4.5:1、关键图形以 3:1 为验证目标。
- 不增加所有节点持续闪烁；沿用现有经典节点效果也需检查“减少动态效果”偏好是否真正作用于 Canvas 循环，不能只检查 CSS。
- 用现有预览检查稀疏和密集图、缩放、拖拽与邻域高亮；视觉修改后再跑项目检查。当前只有调研文档，没有进行渲染性能或无障碍实测。
- 不采用 3D 镜头、自动旋转、视差、流星、随机星点或新渲染依赖。它们增加视觉噪声和成本，也不帮助核对论文关系。

建议下一步产出一张基于真实图谱的“文献星图”对照稿，验证种子、社区与引用证据是否更容易辨认，再决定上线外观。

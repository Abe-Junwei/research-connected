检查日期：2026-11-07。对象：graph.jieyu.ai、Web 入口及适配层、共享图谱核心、OpenAlex/额度代理、VPS 静态部署。Obsidian 插件只验证共享改动兼容性，本轮不安装或更新用户已验收的插件。

## 修复与证据

| 问题 | 处理 | 验证 |
| --- | --- | --- |
| 不同项目标签页各自保存整个设置，可能覆盖另一页的更新 | 浏览器写锁内读取最新值，只合并本页变化；同一数据冲突时拒绝旧写入 | project-store 检查及真实双标签页操作 |
| 新项目保存与读取的规范化不一致，同一页再次保存也可能误报冲突 | 写入前统一规范化项目及阅读记录，再建立比较基线 | 手机新建后选论文，无冲突提示；截图复核 |
| 保存失败后内存可能仍显示未保存状态 | 磁盘写入失败时恢复最新已保存状态，保留既有项目 | 实际收藏按钮触发 QuotaExceededError，验证磁盘与内存 |
| 接管后旧标签页仍可能自动保存或写回任务结果 | 保存入口核对编辑权及任务；失去编辑权即使锁过期也保持只读，重新接管须读取最新值 | 实际点击接管、收藏、旧页强制派发点击和画布动作 |
| 本地已保存，确认扣次断网时未可靠重试 | 在原有效期内用同一幂等键重试，到期保留成果、不追扣 | 故障注入确认响应丢失；客户端虚拟时钟验证到期 |
| 重建时旧图消失；无邻居结果可能替换原图 | Web 更新成功保存后替换，失败、取消、种子单独返回时保留旧图 | 真实操作门控、延迟响应、取消及种子单独返回 |
| 取消、过期或接管后的迟到请求仍可能继续执行 | 操作请求和最终保存检查任务有效性，取消立即使本地任务失效，停止继续请求和保存 | 延迟上游响应后取消，确认旧项目字节不变且不扣次 |
| 同浏览器接管无法释放另一个会话的临时名额 | 仅同浏览器有效会话允许显式接管释放；确认仍校验原会话与幂等键 | 服务端接管、异浏览器拒绝、迟到确认拒绝 |
| 服务端额度文件损坏可能静默重置；落盘失败可能只在内存扣次 | 损坏时拒绝启动；写入失败重新读取磁盘状态，无法恢复则拒绝继续服务 | 损坏 JSON、磁盘替换失败、重启与并发保留测试 |
| 本地代理漏传客户端 API 版本，真实本地操作被误拒绝 | 转发 X-Client-Api | 代理请求头回归 |
| 手机详情仍是抽屉、无独立链接 | 复用现有详情组件，建立论文 URL；浏览器前进/返回恢复详情和图谱；明确深挖按钮 | Chromium 手机触控模拟、URL/前进/返回断言及截图 |
| 直接详情链接忽略本地缓存，缺少摘要与单篇导出 | 本地数据优先，缺失才查询；复用摘要筛查与来源提示，支持三种文本复制和拒绝剪贴板时的可选文本 | 所有 API 503 时本地论文可读且无需文献请求，手动 BibTeX 复制 |

## 实测与限制

首轮公开网络测量见 `web-full-audit-startup-2026-11-07.json`：全新浏览器首开约 5.14 秒，HTML TTFB 约 2.24 秒，后两次同浏览器约 17/18 毫秒。该次为 HTML MISS，约 100 KB 的 JS 已为 CDN HIT；仍存在跨境网络波动，不能把缓存命中等同于所有地区首次访问都快。

最终构建见 `web-full-audit-startup-final-2026-11-07.json`：首开约 6.95 秒，缓存后约 19 毫秒；首开 HTML 和 JS 均为 CDN HIT。拆分测量见 `web-full-audit-network-2026-11-07.json`：HTML TLS 约 0.84 秒，等待约 0.43 秒，100 KB JS 下载约 2.25 秒，JS 到齐到界面就绪约 28 毫秒。显式禁用浏览器代理的独立测量仍首开约 5.29 秒，因此不能归因于本地 HTTP 代理单一因素。VPS 本机静态源站约 0.11 秒、API health 约 0.003 秒。当前剩余延迟主要体现在公开网络的连接及传输，未观察到 JS 执行或等待额度接口导致的秒级阻塞。这些是单机少量样本，不能当成地区或全体用户的性能分位数。

真实建图见 `web-full-audit-live-build-2026-11-07.json`：使用 `10.1038/nature14539`，约 36.56 秒完整保存 50 个节点；成功扣一次，浏览器剩 9 次，全站剩 499 次，数据源保守余额 $0.9994。7 次 OpenAlex 请求均 200，1 次 Semantic Scholar 返回 429，图谱仍正常完成；确认扣次 200、无未捕获浏览器异常。此次明确使用一次正式成功额度。启动测量单独屏蔽 API，仅衡量页面载入，未将建图时长混入首次显示时间。

Safari、真实 iPhone/iPad 和 Android 设备尚未逐一实机验收，手机测试使用 Chromium 触控模拟，不能替代 Safari。未做会耗尽公开额度的压力测试或破坏性生产故障注入；并发和磁盘故障在隔离测试中完成。Semantic Scholar 匿名限流仍是上游约束，允许增强缺失的试运营承诺保持不变。
